Reproduce locally

Clone the repository, install the evaluation dependencies, and run python reproduce.py. The command reconstructs quantitative tables and figures from per-candidate records, then verifies all expected pool sizes. See the repository README for score recomputation from prepared Gaussian-map pairs.
